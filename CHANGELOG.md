# Changelog

## 0.2.2 (2026-10-07)

Five more projects are now named without a link because their repositories may contain the original game's code: mkdd, libsm64, ER Mario, DevilutionX and DevilutionX-D2-Movement.

The OWCraft, ccboy and gang-beasts-rust case studies no longer make claims that their listed sources don't support.

## 0.2.1 (2026-10-07)

The README now links the pull requests that carry these lessons into ai-game-modding-guides and universal-modder.

Eleven new case studies: OWCraft, SubCraft, CrossplayProject, Minebonk, Project Inception, DoomMaps, ccboy, hytale2mc, Insaniquarium Deluxe Revibed, MKX Character Studio and gang-beasts-rust. Guide 01 now links DoomMaps to its case study. Insaniquarium Deluxe Revibed is named without a link because its repository may contain the original game's code.

## 0.2.0 (2026-10-06)

A curated rewrite. This edition replaces the earlier repository contents with a smaller set of method guides and case studies written in our own words. It names only sources with an open licence, an AI credit stated by the project itself, a tool repository, or a public video, and links each one at the commit, tag or video we looked at. It contains no copied code or text from other projects.

Earlier versions (0.1.x) are withdrawn.
