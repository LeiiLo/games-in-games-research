# libsm64: Mario 64 movement as a library

**Repository:** [libsm64/libsm64@fd11813](https://github.com/libsm64/libsm64/tree/fd11813208272b4271d92bd92feb8f3fdbe61be5) (default branch, 6 Oct 2026)  
**Route:** embedded rebuilt mechanic (library)  
**What we read:** README and related project docs. Nothing was run.

A C library built on the Super Mario 64 decompilation. A host feeds it collision and input, steps it, and gets Mario's state and mesh back.

**What we learned:** a decompilation can become a component other games call into. Hosts such as Garry's Mod and [ER Mario](er-mario.md) used it long before the current wave of AI-made mashups, so don't assume AI involvement because a project appears in a recent video.
