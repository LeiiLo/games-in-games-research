# AnyPS5: porting console executables by relinking

**Repository:** [boykopovar/AnyPS5@5895ea7](https://github.com/boykopovar/AnyPS5/tree/5895ea721a43f48547cc996aee0bb65b603622ac) (default branch, 6 Oct 2026)  
**Route:** relinker plus system-library reimplementation (adjacent)  
**What we read:** README and status pages. Nothing was run.  
**AI credit (as the project states it):** commits co-authored by Claude.

Relinks a console program into a native Linux or Windows binary and supplies its own implementations of system libraries, with no emulation.

**What we learned:** its progress badge counts implemented functions against the functions it knows about, and that denominator grows as more are found. A percentage like that measures library coverage, not whether a game runs.
