**What we learned:** a plan and a release are different documents. The first commit contains a long planning document for an agent: in-frame Vulkan/DX12 compositing, depth-aware props, a hidden Garry's Mod owning sandbox physics, native actors mirrored as invisible proxies, 0.01905 m per Source unit and a planned floating origin. The release notes describe a separate overlay window above RDR2 that can't do exclusive fullscreen, and say true in-frame drawing isn't built. Native acceptance is reported on one Windows 11 / NVIDIA / Vulkan PC.

Before you list a feature in your README, check the release notes and the code, not the design doc.
