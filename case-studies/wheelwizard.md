# WheelWizard: a mod manager for Mario Kart Wii

**Repository:** [TeamWheelWizard/WheelWizard@2a68c02](https://github.com/TeamWheelWizard/WheelWizard/tree/2a68c02d2c33c0acdf62a10b39e932abc42b634e) (v2.5.9)  
**Route:** launcher and mod manager  
**What we read:** v2.5.9 source; installers were hashed, not run. Nothing was run.

A manager, updater and launcher for Mario Kart Wii, a popular mod pack, Dolphin and [WiiCompiled](wiicompiled.md). It isn't the recompiler.

**What we learned:** its Dolphin route accepts disc regions and formats that WiiCompiled doesn't, so "supported" depends on which back end you pick. v2.5.9 fixed Linux display-server handling and Flatpak detection. A README note about antivirus false positives isn't an independent scan.
