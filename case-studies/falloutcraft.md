# FalloutCraft: Minecraft inside Fallout 4

**Repository:** [zeyvu/FalloutCraft@cbe85e8](https://github.com/zeyvu/FalloutCraft/tree/cbe85e89f781cfb1db819d13fe8af7656ec12204) (default branch, 6 Oct 2026)  
**Route:** live state bridge (SkyCraft lineage)  
**What we read:** README and history. Nothing was run.

An F4SE plugin and a Fabric mod (Fallout 4 1.11.240, F4SE 0.7.9, Minecraft 26.3).

**What we learned**

- **Guest builds back into the host.** Solid guest blocks become merged native Havok boxes, so NPCs collide with them. They don't path around them; navigation is a separate job.
- **Fork history carries upstream credit.** Its history includes SkyCraft commits co-authored with an AI model. Those describe SkyCraft's work, not the later Fallout-specific changes.
