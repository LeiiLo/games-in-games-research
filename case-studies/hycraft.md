# HyCraft: Minecraft clients on a Hytale server

**Repository:** [EdwardBelt/HyCraft@358bb70](https://github.com/EdwardBelt/HyCraft/tree/358bb700f9e4b7b2b5690ba661444dae714fc13e) (default branch, 6 Oct 2026)  
**Route:** protocol translator (adjacent)  
**What we read:** README. Nothing was run.

A Hytale server plugin that runs a second TCP server and translates Minecraft Java packets into Hytale's protocol.

**What we learned:** "Minecraft in Hytale" can mean a network translator, with no Minecraft code running server-side and no shared simulation. Classify that before comparing it with bridges.
