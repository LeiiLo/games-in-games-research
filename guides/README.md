# Guides

Read them in order the first time. After that, jump to the one your current problem needs.

| # | Guide | Read it when |
|---|---|---|
| 01 | [Choosing a route](01-choosing-a-route.md) | You have an idea and no code yet, or your plan has quietly changed route. |
| 02 | [Bridge contracts](02-bridge-contracts.md) | Two programs will share state. Write this before the bridge. |
| 03 | [Frame compositing](03-frame-compositing.md) | The guest renders its own picture and the host blends it in. |
| 04 | [Geometry transfer](04-geometry-transfer.md) | The host should draw guest meshes with its own lights and shadows. |
| 05 | [Collision and combat](05-collision-and-combat.md) | Players need to stand on, build in or fight in the other game's world. |
| 06 | [A rebuilt engine inside a host](06-rebuilt-engine-in-a-host.md) | You want one game's mechanics (skating, parkour, movement) in another without running the original. |
| 07 | [Reconstruction and fidelity](07-reconstruction-and-fidelity.md) | You're rebuilding a game's systems and need to know whether they match. |
| 08 | [Installers and diagnostics](08-installers-and-diagnostics.md) | You ship several parts (plugin, loader, guest mod, worker) and users get half an install. |
| 09 | [Evidence levels](09-evidence-levels.md) | You're writing up your own work or someone else's. |
| 10 | [Content mods and generated assets](10-content-mods-and-assets.md) | You want new items, units or a whole civ inside one game, with no second game at all. |

The case studies they mention are in [../case-studies/](../case-studies/README.md).
